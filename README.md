# Invoice-Manager-Lite
Invoicing app that helps you to create professional invoices with hundreds free invoice templates in Excel format 

The app is published on Microsoft Marketplace: 
https://marketplace.microsoft.com/en-us/product/WA200000004

To install it:
1. Open Excel for the Web or desktop Excel.
2. Select Home > Add-ins.
3. Select More Add-ins.
4. In the Office Add-ins box, select the Store tab.
5. In the search box, enter "Invoice" (without the quotation marks) to search for apps related to invoicing.
6. In the search results, find Invoice Manager Lite.
7. Click Add to install it in Excel.

For more information:
https://uniformsoftware.com/invoice#lite
